One day, **Cornelius** woke up in a jail cell. Unbeknownst to him, his pet, **Uni**, was tied up to a tree outside. Settings her free might not be the easiest task but surely not impossible. But finding a way out of this puzzling island is no easy feat. Help him explore the island solving puzzles revolving around weird machines accepting lettered tiles as command input.

###

<kbd>Arrows</kbd> or <kbd>W</kbd><kbd>A</kbd><kbd>S</kbd><kbd>D</kbd> to move and <kbd>SPACE</kbd> to interact.
